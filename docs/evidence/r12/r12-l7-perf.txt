work). Each probe interleaves Go and head runs on this machine and keeps its own evidence file; docs/PERF.md

Why R1 reads 3.5 ms where the R1 evidence once read 1.89 ms (inferred, not separately measured): R1 measured
the 0.6 MB CLI skeleton of its own PR; this is the complete 7.2 MB program.

R11 at the earlier head measured a 4.0 MB binary that did not yet embed the 8.2 MB dev UI. With the
UI embedded raw, the real shipped binary was 13.3 MB and its npm tarball 0.303x Go, failing the 0.3x rule.
The UI is now stored brotli-compressed (2.0 MB) and decompressed per request (round trip tested byte for
byte), which brought the binary to 7.2 MB and the tarball to 0.281x. xtask egress masks the brotli static
dictionary (RFC 7932) the decompressor carries and still reports 0 unexpected hosts.
